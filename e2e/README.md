# Тести адмінки

| Команда | Що перевіряє | Час |
| --- | --- | --- |
| `pnpm test` | Логіка: ₴/$ окремо, зміни у %, статуси й бейджі, права овнер/адмін, фільтри з посилань, тексти журналу | ~2 с |
| `pnpm test:e2e` | 5 екранів (Дашборд, Користувачі, Оплати, Ставки, Журнал) на телефоні 390 px і комп'ютері 1440 px | ~1,5 хв |

На GitHub обидва набори запускаються самі при кожному пуші в `master` (`.github/workflows/tests.yml`).
Якщо щось впало — у вкладці Actions є звіт зі скриншотами (`playwright-report`).

## Звідки дані для тестів екранів

Тести не ходять на бекенд: вони підставляють записані відповіді з `e2e/fixtures/api.json`,
а годинник у браузері зупинений на момент запису (щоб «закінчується за 5 днів» не змінювалось).

Якщо екран почав робити новий запит, тест впаде з повідомленням
«requests the recording does not cover». Тоді треба перезаписати відповіді з локального бекенду:

```bash
# бекенд на :3001 з тестовими даними, адмінка на :5174 з VITE_API_URL=http://localhost:3001/api
node e2e/tools/record.mjs <логін овнера> <пароль>
```
